# Trama — web

Sitio de Trama: cobogós y revestimientos de concreto, fabricados en Asunción.

Rutas: `/`, `/tienda`, `/tienda/revestimientos`, `/tienda/cobogos`, `/producto/[slug]`, `/socios`. El carrito es un panel lateral.

```bash
npm install
npm run dev
```

Variable de entorno (opcional, ver `.env.example`): `NEXT_PUBLIC_WHATSAPP`.

Ver `AGENTS.md` para convenciones y estructura.
